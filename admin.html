Required Patch (So Pages Use These Keys)

To allow key rotation without editing code, update: lodge.html and creator-locked.html to read keys from localStorage. Copy/paste the tiny patches below.

Patch for lodge.html (replace MASTER_KEY line)

/* OLD:
const MASTER_KEY = "ARIN-LODGE-KEY-001";
*/

const SAVED = localStorage.getItem("AGEX_MASTER_KEY");
const MASTER_KEY = SAVED && SAVED.trim() ? SAVED.trim() : "ARIN-LODGE-KEY-001";

Patch for creator-locked.html (replace CREATOR_UNLOCK_CODE line)

/* OLD:
const CREATOR_UNLOCK_CODE = "ARIN-CREATOR-KEY-001";
*/

const SAVED = localStorage.getItem("AGEX_CREATOR_KEY");
const CREATOR_UNLOCK_CODE = SAVED && SAVED.trim() ? SAVED.trim() : "ARIN-CREATOR-KEY-001";
