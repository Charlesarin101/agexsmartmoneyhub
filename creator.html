How to operate Creator Wing

Creator Wing is only for Admin. Apprentice users do not need it. You can create tasks anytime (even before Apprentice unlocks). Tasks will simply wait until Apprentice is live. Access approval is manual: when a user submits an unlock request, you approve it here.
